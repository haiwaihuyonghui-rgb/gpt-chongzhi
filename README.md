## 为什么国内开 ChatGPT Plus 难

- OpenAI 官方不支持中国大陆地区。
- 官网结算一般只接受海外发行的银行卡，支付宝、银联卡付不了；国内发行的双币卡也经常被拒。
- 账单地址和卡信息对不上、反复尝试，都会让付款越来越难通过。

## ChatGPT 各档价格

| 档位 | 官方价 | 主要区别 | 适合谁 |
|---|---|---|---|
| 免费版 | $0 | 额度最少，部分地区有广告 | 偶尔用 |
| Go | $8/月 | 比免费版额度高，高级功能少，部分地区有广告 | 轻度使用、预算有限 |
| Plus | $20/月 | 更强的模型、深度研究，Codex 可用 | 每天都用的大多数人 |
| Pro 5X | $100/月 | 额度高很多 | 重度用 Codex、Plus 不够用 |

- Plus 没有固定的每日条数，额度按模型和滚动时间窗口计算；Plus 的 Codex 额度按每 5 小时计算。
- 订阅和 API 分开计费，开了会员不等于有 API 额度。

## 几种开通方式对比

| 方式 | 优点 | 缺点 |
|---|---|---|
| 自己用海外卡订阅 | 官方价，自己掌控 | 国内的卡基本付不了，被拒很常见 |
| 虚拟信用卡 | 按官方价付款 | 开卡费、手续费、汇率差，经常被拒，平台有跑路风险 |
| 外区 Apple ID + 礼品卡 | 不用信用卡 | 要外区账号，步骤多 |
| 合租 / 拼车 | 便宜 | 违反条款、聊天记录不私密、额度被分走、容易被风控 |
| 卡密代充到自己账号 | 支付宝下单，几分钟开通 | 要挑靠谱卖家 |

## GPT 代充怎么挑

1. **充到你自己的账号**，不买成品号、不合租。
2. **不要你的密码**。卡密充值时粘贴的登录信息相当于临时凭证，只粘贴到你信任的充值页面。
3. **有订阅质保**，掉了能补。
4. **价格正常**：几十块的"Plus"常见是退款单、漏洞单，付款一撤销订阅就没了。
5. **能联系到真人**。

## 付款被拒（card declined）排查

| 原因 | 怎么办 |
|---|---|
| 国内发行的卡 | 换海外发行的卡，或改用卡密充值 |
| 账单地址和卡对不上 | 填发卡行登记的真实地址 |
| 同一张卡反复尝试 | 先停一停，别一直点 |
| 网络地区和卡不一致 | 保持网络稳定 |

## 卡密充值失败排查

| 提示 | 原因 | 解决 |
|---|---|---|
| accessToken 已过期 | 复制的登录信息放久了 | 无痕窗口重新登录 ChatGPT，复制后马上提交 |
| 粘贴不进去 / 格式不对 | 没复制完整 | 全选后整段复制粘贴 |
| 通道暂时不可用 | 通道在补充额度 | 卡密不会被扣，稍后再试或联系卖家 |
| 显示成功但看不到 Plus | 页面没刷新 | 退出重新登录，App 下拉刷新 |
| 一直转圈 | 上游还在处理 | 不要重复提交，等 3 分钟再看 |

## 降低被封风险的习惯

- 网络保持稳定，不要频繁切换国家。
- 一个账号只给自己用。
- 不要用脚本批量调用网页版。
- 被停用时先看邮箱通知，按官方指引申诉；订阅费按条款一般不退。

## 常见问题

**已经是会员了，代充能直接续吗？**
当前订阅到期后再充值最稳；到期前重复充值可能提示"已有订阅"。

**取消自动续费后会员马上没吗？**
不会，已付费的周期会用到到期日。

**ChatGPT 可以用支付宝吗？**
官网不能直接用支付宝。可以用支付宝买卡密，充到你自己的账号。
